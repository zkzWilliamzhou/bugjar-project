# Grilling

- Ask exactly one question at a time. Never a batch of five.
- Every question carries a recommended answer and a reason it might be wrong.
- Ask dependencies first, dependents later. Ask about evidence before opinion.
- Keep asking until an implementer could build the thing without asking a single question.
- Record resolved decisions in CONTEXT.md and record rejected alternatives as ADRs.
- A spec is not done while a question remains. Do not start work to escape the interview.
