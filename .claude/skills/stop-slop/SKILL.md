# Stop slop

Score any prose on directness, rhythm, trust, realness and density, 1-10 each. Below 35/50, rewrite it.

Banned: throat-clearing openers ("Here's the thing", "In today's fast-moving world"); binary contrasts ("Not because X. Because Y."); business jargon ("game-changer", "deep dive", "navigate challenges"); adverbs used as emphasis crutches; vague declaratives ("the implications are significant"); false agency ("the data tells us"); dramatic fragmentation; filler summaries of what was just said.

Prefer: short factual sentences, concrete numbers, named files, exact commands. Say what the tool does, then say what it does not do. Never generate an explanation that is not backed by a value from the data. All generated reports must cite the field they came from.
